# SIH 2026 - React + Vite Frontend Setup

This directory contains the **React.js (Vite)** frontend setup for the SIH 2026 project.

## 📁 Project Structure

```
FRONTEND/
├── index.html          # HTML Entry Point
├── package.json        # Dependencies & Scripts
├── vite.config.js      # Vite Configuration
├── src/
│   ├── main.jsx        # React DOM Root Renderer
│   ├── App.jsx         # Main React App Container
│   ├── index.css       # Global Modern Styling System
│   └── components/
│       ├── Navbar.jsx    # Sticky Navigation Bar
│       ├── Hero.jsx      # Hero Banner Component
│       ├── Features.jsx  # Key Features Grid Component
│       ├── Dashboard.jsx # Interactive Status Dashboard
│       └── Footer.jsx    # Footer Component
└── README.md           # Documentation
```

## 🚀 Quick Start Instructions

1. **Install Dependencies**:
   ```bash
   cd FRONTEND
   npm install
   ```

2. **Start Development Server**:
   ```bash
   npm run dev
   ```

3. **Build for Production**:
   ```bash
   npm run build
   ```
